Rules sheet

Typography and spacing, version 1.2, 26 Nov. Full Inter with "ss02" on. Every sample below is drawn with the rule it shows.

Read it top to bottom and mark anything you'd change. Nothing in the hi-fi changes until you say go. The text version is rules/typography-and-spacing.md.

1. Typefaces

Two typefaces. Inter for everything people read or press. Barlow Condensed only for the page name, in capitals.

Barlow 700

Page names only: TODAY, INBOX, PROJECTS

4. Long text

Names and articles can run to 10+ words. Each role decides up front: wrap or cut.

List rows stop at 2 lines with "…" and the full text on hover. Grey side text stops at 220 px. The tag never shrinks.

5. Spacing scale

Everything sits on a 4 px grid. Only these steps; never 2, 6, 10, 14 or 18.

space-14label → field, title → subtitle
space-28between buttons, group label → list, hint → main button
space-312fact rows, fields in a form, parts of a decision
space-416panel padding, between blocks, work ↔ panel
space-520page top
space-624between sections, above a group label, page bottom
space-832page sides

space-1456rare: empty states
