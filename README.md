# Uniframe portal, clickable prototype

Static site, no build step. Open `index.html` or serve the folder.

- All names, numbers and amounts are example data (`js/data.js`). Quote O2611-010 follows the layout of Uniframe's own Offerte.
- The calculation and the quote document edit the same lines; the agent panel re-checks them on every change. Edits stay in your own browser (localStorage) and can be reset on the page.
- Styles: `css/uniframe-tokens.css` and `css/uniframe-portal.css` are copies of the design-system files in `Uniframe brand guideline/tokens`. `css/site.css` is prototype layout.
- Icons: `js/icons.js`, drawn like the logo. Sheet: `icons.html`.
